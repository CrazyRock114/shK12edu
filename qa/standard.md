# 交付标准

**范围**: `https://sh-k12edu.vercel.app`,两个子站 `/eng-g3a/` 和 `/eng-g5a/`,各 11 单元 (starter + unit1-10)。

## 6 条标准

1. **进得去**:所有单元 URL 200,索引页 12 张卡都能点
2. **听得见**:教材原声整段 + sections 切片 + TTS 三种音频都能播
3. **看得清**:教材原图跟课本一致,单词图能看清
4. **点得动**:5 个阶段 tab + section 按钮 + 闪卡 + 游戏 都能交互
5. **看得懂**:中文释义 + 拼音/翻译,三年级用图多,五年级可以用文字
6. **不出错**:点任意按钮不崩,console 无 error,404 不出现

**等级**:6 条全过 = 🟢 生产 / 5 条 = 🟡 Beta / 4 条 = 🟠 Alpha / ≤ 3 条 = 🔴 不过

## 已知差距(目标模式发现时直接归"差距"不重提)

- g3a / g5a 用单页 `unit.html` + URL `?unit=N` 动态切换,不是 12 个静态页
- sections_data.js 控制各单元的 section 列表
- 教材来源:smartedu.cn (3 年级沪教版 + 5 年级沪教版)
