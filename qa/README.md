# QA

2 份文档,目标模式用。在 git 仓库外(`site/` 同级),不会污染 commit。

| 文件 | 用途 |
|---|---|
| `standard.md` | 6 条交付标准(进得去/听得见/看得清/点得动/看得懂/不出错) |
| `target-mode.md` | 目标模式提示词,新会话粘贴整段开始检查 |

## 范围

`https://sh-k12edu.vercel.app` 下的:
- `/eng-g3a/` — 三年级英语上册,11 单元
- `/eng-g5a/` — 五年级英语上册,11 单元

## 用法

1. 开新对话
2. 复制 `target-mode.md` 里"提示词"那一整段(包括 ``` 代码块)粘到新对话
3. agent 自动跑 6 步检查
4. 报告回 `qa/report-{日期}.md`,对话里给概要
